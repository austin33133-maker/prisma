# 卖家精灵(SellerSprite)产品调研报告

## 1. 产品概况

卖家精灵(SellerSprite)是一款面向亚马逊卖家的大数据选品与运营 SaaS 工具,由成都云雅信息技术有限公司开发,在中国卖家群体中渗透率极高,同时提供英文版面向海外卖家。

- **产品形态**:Web 端 + 浏览器插件(Chrome / Firefox / Edge),会员通用。
- **功能规模**:30+ 核心功能,覆盖「选品 → 选词 → 运营推广 → 监控」全链路。
- **数据规模**:近 2000 万动销 ASIN,按周/月更新;竞品历史销量可回溯 24 个月以上。
- **站点覆盖**:美国、日本、英国、德国、法国、意大利、西班牙、加拿大、印度、墨西哥等 10 个亚马逊站点。

## 2. 核心功能矩阵

### 2.1 选品类(Product Research)

| 功能 | 说明 |
|---|---|
| 大数据选品 | 按价格、预估销量、竞争度、增长趋势等多维条件筛选潜力商品 |
| 竞品查询 | 输入 ASIN 查询历史销量、价格、BSR、评论数的时间序列 |
| 市场分析 | 类目市场容量、竞争格局、供需关系、垄断度分析 |
| 商品监控(Product Tracker) | 持续追踪指定 ASIN 的销量/价格/评论变化并告警 |
| 店铺跟踪 | 监控竞争对手店铺的新品与动销情况 |
| 全球品牌库 | 品牌维度的商品与卖家数据检索 |

### 2.2 关键词类(Keyword Research)

| 功能 | 说明 |
|---|---|
| 关键词挖掘(Keyword Miner) | 动态挖掘搜索词的关联长尾词,静态定位高转化核心词 |
| 反查 ASIN(Reverse ASIN) | 一键反查竞品的自然流量词与广告流量词 |
| 关键词排名追踪 | 实时追踪关键词的自然排名与广告排名 |
| 关键词批量筛选 | 批量判断关键词与商品的相关性 |
| 搜索量与购买率 | 提供亚马逊关键词的精准搜索量及购买转化率 |
| 广告洞察(Ads Insights) | 竞品广告投放策略分析 |

### 2.3 运营辅助类

- Listing 打分与优化建议(基于关键词覆盖度)。
- 插件端「页面即数据」:在亚马逊搜索页/详情页直接叠加销量、利润、关键词数据。
- 利润计算器、FBA 费用估算。

## 3. 商业模式与定价

- **免费层**:插件部分基础功能免费(查询次数受限),作为获客漏斗。
- **付费订阅**(2026 年参考价):
  - Standard:$79/月,年付 $790(约 8.3 折)。
  - Advanced / VIP:面向团队与代运营公司,提供更高查询额度、更多子账号。
  - **付费版功能全量开放,套餐差异主要在「额度」**(可追踪的商品数、关键词数、店铺数、导出次数)而非功能开关——这是其定价设计的关键特征。
- **API 服务**:数据 API 单独售卖,面向 ERP/BI 集成场景。

## 4. 竞品格局

| 竞品 | 定位差异 |
|---|---|
| Helium 10 | 海外市场领导者,功能最全,价格更高($99+/月) |
| Jungle Scout | 选品起家,数据口径以美国站为主 |
| 欧鹭(OALUR)、西柚找词 | 国内同类,数据深度略浅 |
| SIF、Smartscout | 细分场景(关键词/批发选品)工具 |

卖家精灵的护城河:**中文卖家生态(教程/社群/客服)+ 高性价比 + 插件体验 + 24 个月历史数据深度**。

## 5. 关键洞察(对自研产品的启示)

1. **数据是核心壁垒,功能是数据的呈现**。所有功能本质上是对「ASIN 时间序列 + 关键词图谱」两张大表的不同切面查询。
2. **插件是获客入口,Web 是变现主场**。免费插件降低使用门槛,深度分析引导付费。
3. **按额度而非按功能收费**,降低用户决策成本,提高转化。
4. **销量预估算法是口碑生命线**:基于 BSR 曲线 + 评论增速 + 类目系数的混合模型,准确度直接决定用户留存。
