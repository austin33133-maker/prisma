## 1. 品牌使命

**给每个出海的人呐喊助威。**

出海不是大卖的专利。每一个在深夜核算汇率的个人卖家、每一个押上积蓄发第一柜货的小团队、每一个被广告费烧到失眠的运营,都值得拥有和头部玩家同一水平的数据武器。我们做这款产品,不是再造一个工具,而是站在每个出海的人身后——他们扬帆,我们呐喊;他们冲锋,我们递刀。

### 1.1 品牌宣言(Manifesto,可直接用于官网首屏/发布会)

> 海的那边没有秘密,只有还没被看见的数据。
>
> 有人说选品靠运气,我们说运气是别人家的算法。
> 有人说小卖家拼不过资本,我们说信息平权就是最大的资本。
>
> 你敢把货发向太平洋的另一端,
> 我们就敢把 2000 万个 ASIN 的真相摆在你面前。
>
> 每一条 BSR 曲线,都是我们为你探好的航道;
> 每一次关键词反查,都是我们替你侦察的敌情;
> 每一条断货告警,都是我们在桅杆上为你喊出的风暴预警。
>
> 出海的人,从来不是一个人。
> ——我们在数据里,为你呐喊助威。

## 2. 与卖家精灵的逐项对标

策略基调:**功能上「跟齐主航道、突袭薄弱点」,体验和情感上全面差异化。** 对手 8 年数据积累无法速胜,正面战场打平即可,胜负手放在体验、社群与价格。

### 2.1 功能对标矩阵

| 能力 | 卖家精灵(对手现状) | 扬帆数据 MVP | 对标策略 |
|---|---|---|---|
| 竞品历史数据 | 24+ 个月回溯 | 12 个月起步,逐月自然累积 | **跟随**:深度短期追不上,以「数据新鲜度 + 更新频率」对冲 |
| 销量预估 | 黑盒数值 | 数值 + **置信区间 + 模型版本可回溯** | **突袭**:用「敢晒误差」建立信任,打对手黑盒痛点 |
| 反查 ASIN | 自然词 + 广告词 | 同等能力(`KeywordRanking` 倒排,见文档 3) | **跟齐**:核心刚需,不能缺席 |
| 关键词挖掘 | 长尾词 + 搜索量 + 购买率 | 同等能力 + 词根聚类可视化 | **跟齐微创新** |
| 商品/关键词监控 | 有,告警维度固定 | 告警规则用户自定义(`alertConfig` Json,见文档 3) | **突袭**:灵活性取胜 |
| 浏览器插件 | 成熟,免费引流主力 | 二期补齐 | **暂避**:MVP 不打,Web 端做深 |
| 站点覆盖 | 10 站点 | 美国站 → 日本/欧洲 | **聚焦**:单点打透再扩 |
| Listing 打分 / 利润计算 / 广告洞察 | 有 | 不做(二期) | **舍弃**:避免战线过长 |
| API 服务 | 单独售卖 | MVP 即开放(随付费套餐赠基础额度) | **突袭**:讨好技术型卖家与 ERP 生态 |

### 2.2 定价对标

| 维度 | 卖家精灵 | 扬帆数据 |
|---|---|---|
| 入门付费 | Standard $79/月,年付 $790 | **$49/月,年付 $470**(锚定对手 6 折) |
| 免费层 | 插件基础功能限次 | Web 端核心查询每日限次 + **新卖家前 90 天额度翻倍**(「首航礼包」) |
| 套餐逻辑 | 功能全开、按额度分层 | **沿用**(已被验证,见文档 1 §5),但额度计量全部透明可视 |
| 团队/子账号 | VIP 套餐 | Advanced 即含 3 个子账号,降低小团队门槛 |

### 2.3 体验与情感对标(差异化主战场)

1. **「呐喊助威」产品化**,把品牌主张做进功能而不是只挂在官网:
   - **首航里程碑**:用户第一次出单、第一次进 Top 100、第一次盈利,产品内庆祝动画 + 可分享战报海报(自带传播)。
   - **风暴预警语态**:告警文案从冷冰冰的「BSR 下降 32%」改为「⚠️ 侧翼遭袭:竞品 B0XXXX 正在抢你的『yoga mat』自然位,这是它的弹药(反查链接)」。
   - **同行者社区**:按类目匿名组队的「船队」,共享市场水位数据,周报互助。
2. **透明对抗黑盒**:每个预估数字可点开看「怎么算的」——数据来源、模型版本、置信区间。对手做不到,因为黑盒是它的既得利益。
3. **中文服务的下一代标准**:对手靠教程和客服赢了上一代;我们加上「开箱即用的打法模板」——选品 SOP、新品推广日历直接内嵌在工具流程里。

## 3. 传播打法(GTM)

| 阶段 | 动作 | 对标意图 |
|---|---|---|
| 冷启动 | 知乎/公众号/视频号发「销量预估误差公开测试」系列,拿自家与对手对同一 ASIN 的预估 vs 真实订单对比 | 用「透明」碰瓷「黑盒」,低成本建立专业心智 |
| 公测 | 「首航计划」:前 1000 名新卖家免费用 Advanced 90 天,换取案例与战报素材 | 对手服务存量大卖,我们抢增量新卖家 |
| 增长 | 战报海报分享裂变 + 类目船队邀请制 | 把「呐喊助威」变成可传播的社交货币 |
| 生态 | API 免费额度 + ERP/插件开发者分成 | 在对手单独收费的 API 上建开放生态 |

## 4. 北极星指标

- **北极星**:每周完成「查询 → 加入追踪」完整动作的活跃卖家数(代表真实依赖,而非围观流量)。
- 护栏指标:销量预估 P50 相对误差 ≤ 25%(公开承诺);告警送达延迟 P95 ≤ 10 分钟。

## 5. 一句话总结

卖家精灵证明了这个市场的需求和定价模型;**扬帆数据不和它比谁的数据库更老,而是比谁更站在出海人一边**——更透明的数据、更便宜的入场券、更有温度的呐喊。
